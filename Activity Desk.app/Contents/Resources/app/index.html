Which token should I use?
  • Fine-grained works for the stream and insights. For private events, add the account permission Events: read. For private pull request details, give it access to those repositories with Pull requests: read.
  • Classic with repo, read:user and notifications also unlocks unread notifications, which GitHub does not give fine-grained tokens.
  • Activity Desk encrypts the saved token using macOS Keychain and sends it only to api.github.com.

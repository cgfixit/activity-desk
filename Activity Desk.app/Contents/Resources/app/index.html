Which token should I use?
  • Fine-grained (recommended) works for the stream and insights. Set the resource owner to your account and grant read-only access only. For private events, add the account permission Events: read. For private pull request details, give it access to those repositories with Pull requests: read. For private issue conversations, add Issues: read. For repository traffic in Footprint, add Administration: read. A fine-grained token covers one account or organization.
  • Classic with notifications enables the unread inbox. GitHub's classic repo scope also grants write access to private repositories.
  • Activity Desk encrypts the saved token using macOS Keychain and sends it only to api.github.com.

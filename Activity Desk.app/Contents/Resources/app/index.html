The public view shows public events, repositories, and stars. The contribution calendar, pull request details, conversations, notifications, traffic, and notes need a token. GitHub allows 60 requests an hour without one.

Which token should I use?
  • Fine-grained (recommended) works for the stream and insights. Set the resource owner to your account and grant read-only access only. For private events, add the account permission Events: read. For private pull request details, give it access to those repositories with Pull requests: read. For private issue conversations, add Issues: read. For repository traffic in Footprint, add Administration: read. A fine-grained token covers one account or organization.
  • Classic with notifications enables the unread inbox, which GitHub serves only to classic tokens. GitHub's classic repo scope also grants write access to private repositories.
  • Both work together. Sign in with either one, then add the other for the same account in Data & access. Activity Desk reads notifications with the classic token and joins what each token can see.
  • Activity Desk encrypts saved tokens using macOS Keychain and sends them only to api.github.com.
